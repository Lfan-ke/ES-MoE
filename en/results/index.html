    Results¶

    Every row is one run record in results/, and this page is generated from them by scripts/report.py. Arms are grouped by backbone, block configuration and budget, so two different budgets never land in the same average. Read the paired tables rather than the two means, and read limitations before quoting a number; cell-by-cell verdicts are on the judgment lines page.

    Every protocol-matrix best.pt and its full training arguments live on the checkpoints branch (Git LFS, isolated from main; that branch's README states how many): every bucket and routing number recomputes from them.
